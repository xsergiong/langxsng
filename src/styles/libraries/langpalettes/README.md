# DOCUMENTATION OF USE

## Colors
To indicate a background color, you must first indicate the palette it is a part of with one of these classes:
- Green
- Purple
- Red
- Pink
- Blue

Then, you will need to specify the the shade inside the palette (c + 0–7) with an additional class.

If you wish to do the same with the text color, the only thing you will need is placing "text" followed by a hyphen before the color class.
